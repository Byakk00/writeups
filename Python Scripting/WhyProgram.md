## Autograder: Write Hello World

Write a program in Python to print "hello world".

```py
# the code below almost works
prinq("hello world")
```

We see an error here, to print we use 'print' not 'prinq'.

## Solution

```py
# the code below almost works
print("hello world")
```

Output: hello world

Used 'print("hello world")' to print the string "hello world".
